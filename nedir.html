Mülakat Öncesi Hızlı Öğrenme

React Native, TypeScript ile iOS ve Android arayüzü yazmayı sağlar. CLI native toolchain'i yönetir. TypeScript veri şekillerini derlemede kontrol eder.

Temel kavramlar

Zustand
Local UI state store'udur.
React Query
Server state, cache, retry ve loading/error yönetir.
Axios
HTTP istekleri için istemcidir.
REST ve POST
HTTP endpoint modeli ve veri/işlem gönderme metodudur.
multipart/form-data
Binary dosyayı form alanlarıyla taşır.
ASP.NET Core
Gemini key'i mobile dışında tutan tip güvenli backend'dir.
Gemini multimodal AI
Metin ve görseli birlikte yorumlar; JSON sözleşmesi güvenli parse sağlar.
Adapty/paywall/entitlement
Abonelik altyapısı, teklif ekranı ve premium hakkıdır.
API key/environment variable
Gizli bilgi ve kod dışı config'tir; mobile konmaz.
CORS
Origin erişim politikasıdır.
async/await
Ağ/dosya beklerken akışı bloklamaz.
Loading/Error/Empty
Kullanıcıya durum ve sonraki eylemi anlatır.
Component architecture
Button/Card gibi tekrar kullanılabilir UI parçalarıdır.

25 mülakat sorusu — kısa cevaplar

  1. Query + Zustand? Server cache ve local state ayrılır.
  2. Gemini backend? Secret ve validation merkezi olur.
  3. Key koruma? Secret manager/environment.
  4. Upload optimizasyonu? Resize, compress, cancellation.
  5. Büyük görsel? MIME/boyut kontrolü ve resize.
  6. REST/WebSocket? Request-response / sürekli kanal.
  7. RN performansı? Render, list ve image memory ölçülür.
  8. Adapty? Store farklılıklarını abstraction eder.
  9. Production key? Key Vault ve managed identity.
  10. ASP.NET? Tip güvenliği ve middleware.
  11. Bozuk AI JSON? Validate ve fallback.
  12. Demo mode? Key olmadan geliştirme.
  13. Multipart? Binary için uygundur.
  14. Timeout? Sonsuz beklemeyi önler.
  15. CORS prod? Bilinen originler.
  16. Rate limit? IP/user quota.
  17. Auth? JWT/OIDC ve user quota.
  18. History? DB metadata + object storage.
  19. Prompt version? Sonuçla sürüm saklanır.
  20. Maliyet? Resize, cache, quota.
  21. Accessibility? Label, contrast, target.
  22. Testing? Integration ve component tests.
  23. Retry? Geçici ağ/5xx'te.
  24. Cancellation? Unmount'ta iptal.
  25. Deployment? CI, hosting, signed builds.
