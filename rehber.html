AI Photo Analyzer — Kurulum Rehberi

Gereksinimler

Windows: Node.js LTS, Git, .NET 8 SDK, Android Studio, Android SDK ve JDK. iOS için macOS ve Xcode gerekir.

Backend

cd backend
dotnet restore
dotnet run

http://localhost:5080/api/health ve /swagger adreslerini açın.

Gemini API key

Google AI Studio üzerinden key alın. backend/appsettings.Development.example.json dosyasını appsettings.Development.json olarak kopyalayıp Gemini:ApiKey alanına yapıştırın. Key'i GitHub'a commit etmeyin. Key yoksa Demo Mode çalışır.

Android

cd mobile
npm install
npx react-native start
npx react-native run-android

Emulator URL'si mobile/src/constants/config.ts içinde http://10.0.2.2:5080. Fiziksel cihazda bilgisayarın LAN IPv4 adresini yazın.

iOS

cd mobile
npm install
cd ios
pod install
cd ..
npx react-native run-ios

Windows'ta iOS çalıştırılamaz; macOS + Xcode gerekir.

Adapty

Public key'i mobile/src/constants/config.ts içindeki ADAPTY_PUBLIC_SDK_KEY alanına yazın. Boş key ile Demo Mode çalışır.

Sorun giderme

Backend açık mı kontrol edin. Android'de localhost kullanmayın. Cache: npx react-native start --reset-cache.
